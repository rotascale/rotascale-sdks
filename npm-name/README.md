# rotascale

The TypeScript SDK is published as **[`@rotascale/sdk`](https://www.npmjs.com/package/@rotascale/sdk)**.

```sh
npm install @rotascale/sdk
```

The Python SDK is [`rotascale`](https://pypi.org/project/rotascale/) on PyPI.

This package holds the unscoped name so it cannot be taken by someone else. It
contains no code and is not a dependency of anything.

— <https://rotascale.com>
